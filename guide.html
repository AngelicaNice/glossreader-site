Как поставить

Сборка для Mac на чипе Apple и для Windows 10/11. Программа без подписи магазина: система один раз спросит разрешение, дальше открывается как обычно.

Скачать для Mac Скачать для Windows

Mac

Нужен чип M1, M2, M3 или M4. Intel Mac не поддерживается.

1. Скачай GlossReader.dmg, открой его и перетащи GlossReader в папку «Программы».

2. В Finder: правый клик по GlossReader → «Открыть» → ещё раз «Открыть».

3. Если система предлагает только «Переместить в Корзину», открой Терминал и выполни команду ниже. Потом снова правый клик → «Открыть».

xattr -cr /Applications/GlossReader.app

Первый запуск может занять около минуты: в базу кладётся словарь.

Windows

Windows 10 или 11, 64-bit, Intel или AMD. Сборки для ARM-ноутбуков Windows пока нет.

1. Скачай GlossReader-amd64-installer.exe и запусти его.

2. Если SmartScreen пишет «неизвестный издатель»: «Подробнее» → «Выполнить в любом случае».

3. Запрос прав администратора нужен, чтобы поставить программу и при необходимости WebView2 — без этого движка окно не откроется.

Субтитры

В библиотеке есть «+ Субтитры». Нужен файл .vtt, не ролик. Если установлен yt-dlp, текст субтитров с YouTube сохраняется так:

yt-dlp --skip-download --write-subs --write-auto-subs \
  --sub-langs "en,en-orig" --sub-format vtt \
  -o "%(title)s.%(ext)s" "URL_РОЛИКА"

На Mac yt-dlp ставится командой brew install yt-dlp. Скачивается текст, не видео.

Караоке по аудиокниге

Добавь свою аудиокнигу и нажми «Синхронизировать речь». Распознавание уже внутри GlossReader. В первый раз скачается модель, около 150 МБ, для этого нужен интернет. Дальше всё считается на этом компьютере. Пока модель качается, книгу можно читать.

Разбор фраз

В Настройках выбирается модель. Подсказка есть и в самой панели разбора.

Бесплатно и без VPN работает модель на этом же компьютере. В Настройках — провайдер «Свой (OpenAI-совместимый)».

Адрес APIhttp://127.0.0.1:1234/v1http://127.0.0.1:11434/v1
API-ключпустопусто
Модельимя загруженной в LM Studioкак в ollama list, например qwen2.5:7b

В LM Studio включи Local Server. В Ollama сначала ollama pull qwen2.5:7b.

Облачные ключи тоже бывают бесплатными. Запрос идёт из GlossReader, поэтому VPN, если он нужен, должен быть включён на компьютере, не только в браузере.

  • Gemini. Пункт в Настройках. Ключ: aistudio.google.com/apikey, кнопка Create API key. Карта обычно не нужна. Модель по умолчанию gemini-2.5-flash.
  • Groq. Ключ: console.groq.com/keys, без карты. Модель по умолчанию llama-3.1-8b-instant.
  • OpenRouter. Провайдер «Свой», адрес https://openrouter.ai/api/v1, ключ с openrouter.ai/keys, модель с суффиксом :free или openrouter/free.

Ключи OpenAI и Anthropic почти всегда платные. Подписка ChatGPT, Claude или Gemini в браузере к программе не подключается.

Anki

Слова остаются в GlossReader, даже если Anki нет. Чтобы сделать карточки, нужны Anki Desktop и дополнение AnkiConnect. Оба ставятся отдельно.

1. Скачай Anki с apps.ankiweb.net. На Mac бери версию для Apple Silicon. Запусти и разреши открытие, если система спросит.

2. В Anki: Инструменты → Дополнения → Получить дополнения. По-английски: Tools → Add-ons → Get Add-ons. Вставь код 2055492159. Это AnkiConnect.

3. Перезапусти Anki и оставь его открытым. В GlossReader нажми «В Anki».

Колода по умолчанию называется как книга. Для вставленного текста — как ты его назвал. В Настройках можно проверить, запущен ли Anki, и сложить все книги в одну колоду. Если Anki закрыт, кнопка скажет, что он недоступен. Слова в читалке при этом остаются.

Где лежат книги и слова

На Mac: ~/Library/Application Support/GlossReader. На Windows: %AppData%\GlossReader. Удаление программы эту папку не стирает.

Ранние сборки хранили то же самое в папке MyReader. Новая сборка при первом запуске переименовывает её сама, если GlossReader ещё нет. Можно перенести заранее, пока программа закрыта:

  • Mac. В Finder: «Переход» → «Переход к папке…», вставь ~/Library/Application Support. Переименуй MyReader в GlossReader.
  • Windows. Нажми Win+R, вставь %AppData%, Enter. Переименуй MyReader в GlossReader.
