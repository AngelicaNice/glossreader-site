GlossReader

EPUB, PDF и свой текст. Словарь, подсветка по уровню, озвучка и караоке по твоей аудиокниге.

Скачать для Mac Скачать для Windows

Mac: чип Apple (M1 и новее), не Intel. Windows: 10/11, 64-bit.

Как открыть

Сборка без подписи Apple и Microsoft. Система спросит, это нормально.

  • Mac. Перетащи GlossReader в Программы. Правый клик по программе → Открыть → ещё раз Открыть. Если видна только Корзина, в Терминале: xattr -cr /Applications/GlossReader.app, затем снова правый клик → Открыть.
  • Windows. Запусти установщик. В окне SmartScreen: Подробнее → Выполнить в любом случае. Если спросит права администратора — это чтобы поставить программу и, при необходимости, WebView2.

Первый запуск может занять около минуты: в программу кладётся словарь.
